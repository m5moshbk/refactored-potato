# قسم المتاجر — M5mOsH Nexus

يجمع هذا القسم المتاجر وبوابات الأعمال. التصنيف لا يعني أن الدفع أو الطلبات الخلفية تعمل.

| المستودع | المهمة | الملاحظة |
|---|---|---|
| [super-duper-octo-adventure](https://github.com/m5moshbk/super-duper-octo-adventure) | واجهة AUS Luxe لإكسسوارات السيارات | المصدر المسجل لمعاينة Render في الجرد السابق؛ تحقق من backend والطلب والدفع |
| [aus-luxe-auto-store](https://github.com/m5moshbk/aus-luxe-auto-store) | مستودع آخر باسم AUS Luxe | مرشح للمقارنة؛ لا تحذفه قبل مقارنة الملفات والفروع والتاريخ |
| [Tamara-Business-Site](https://github.com/m5moshbk/Tamara-Business-Site) | واجهة أعمال لعرض خدمات Tabby وTamara | نموذج أولي؛ لا يثبت معالجة مدفوعات حقيقية |

## قواعد القسم
1. مصدر أساسي واحد لكل متجر بعد المقارنة.
2. فصل الواجهة عن API والدفع والطلبات الخلفية.
3. لا تخزن أسرار بوابات الدفع أو بيانات العملاء في GitHub.
4. لا تحذف أو تؤرشف مستودعًا متشابهًا قبل فحص المحتوى الفريد وروابط النشر.
