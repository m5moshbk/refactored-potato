# صدى الحرف — M5mOsH Voice Nexus

منصة عربية للتواصل الصوتي وإمكانية الوصول، تجمع بين الكلام إلى نص، والنص إلى صوت، ولوحة عبارات مساعدة.

## ما يعمل في النسخة الحالية
- واجهة Next.js عربية RTL ومتجاوبة.
- التعرف على الكلام من خلال واجهة المتصفح عند دعمها، وبعد موافقة المستخدم.
- نطق النص عبر Speech Synthesis المتاح في المتصفح.
- لوحة عبارات سريعة قابلة للتعديل والنطق.
- API أولي لتسجيل الحسابات وتسجيل الدخول والجلسات.
- واجهة تقييم فجوات لا تنفذ تغييرات تلقائية.

## ما لم يُفعّل بعد
- تحويل الكلام إلى نص على الخادم.
- التحقق البيومتري من هوية المتحدث.
- كشف الصوت الاصطناعي أو المعاد تشغيله.
- لوحة المؤسسات وعزل المستأجرين.
- ترحيلات قاعدة البيانات واختبارات الإنتاج.

## التشغيل المحلي

### Backend
```bash
cd backend
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

أنشئ مفتاحًا عشوائيًا خاصًا بك بطول 32 حرفًا على الأقل في `.env` ثم:

```bash
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

### Frontend
```bash
cd frontend
cp .env.example .env.local
npm install
npm run dev
```

## واجهات API
- `GET /health`
- `POST /api/v1/signup`
- `POST /api/v1/login`
- `GET /api/v1/me` — يتطلب Bearer token
- `POST /api/v1/transcribe` — يتطلب مصادقة؛ الخدمة الخادمية غير مهيأة حاليًا
- `POST /api/v1/voiceprint` و`POST /api/v1/verify` — غير متاحين حتى دمج نموذج بيومتري مختبر
- `GET /api/v1/evolution` — تقييم فجوات حتمي للقراءة فقط

## ملاحظات الخصوصية
- الميكروفون لا يبدأ إلا بعد ضغط المستخدم والموافقة.
- التعرف الصوتي في المتصفح قد يستخدم خدمة يوفرها المتصفح؛ راجع سياسة مزوده.
- الواجهة الحالية لا ترفع التسجيل الصوتي إلى خادم المشروع.
- لا تستخدم hash لملف صوت كبديل عن بصمة المتحدث.
- لا تفعّل التحقق الصوتي قبل الموافقة، ومقاومة الانتحال، والاختبارات، والتشفير، وإمكانية سحب الموافقة والحذف.
