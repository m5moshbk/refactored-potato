# بوت فهرس M5mOsH Nexus

بوت Telegram للقراءة والاستعراض فقط، يعرض المستودعات والأقسام والغرض وطريقة الاستخدام والمكونات وروابط GitHub.

## الأوامر
- /start أو /help
- /sections
- /repos
- /stores
- /tools
- /unclassified
- /services — خدمات Render
- /service اسم-الخدمة — تفاصيل الخدمة ورابطها ولوحة إدارتها
- /projects — المشاريع الأساسية
- /repo اسم-المستودع
- /search كلمة (يبحث في المستودعات والخدمات)

## نشر Render
- Runtime: Python
- Build command: echo "No third-party dependencies"
- Start command: python telegram_bot/bot.py
- Health path: /health
- `TELEGRAM_BOT_TOKEN`: مطلوب لتلقي أوامر Telegram.
- `TELEGRAM_ADMIN_CHAT_ID`: مطلوب لتحديد محادثة الإدارة؛ عند غيابه لا تُمنح أي محادثة صلاحيات الإدارة.
- `NEXUS_PUBLIC_MODE`: الافتراضي `0`؛ دردشة AI العامة متوقفة ما لم تُفعّل صراحةً بالقيمة `1`.
- `NEXUS_PUBLIC_DAILY_LIMIT`: حد الرسائل لكل محادثة خلال 24 ساعة عند تفعيل الوضع العام (من 1 إلى 100).

لا تضع رمز البوت أو مفاتيح AI في GitHub. أضف الأسرار من إعدادات Environment في Render فقط. من دون رمز البوت تعمل نقطة الصحة فقط. لا يُثبت هذا التغيير قيمة متغيرات الإنتاج الحالية؛ لا بد من مراجعة إعدادات الخدمة بشكل منفصل قبل أي قرار تشغيلي.

## ملاحظة الدقة
الكتالوج أولي؛ المستودعات التي لم تُراجع ملفاتها موسومة بحاجة للتصنيف. البوت يعرض ملف catalog.json ولا يجلب بيانات GitHub الحية لكل استعلام. لا يدعم الحذف أو النشر أو تعديل المستودعات.


## مراقبة منشورات القنوات وتحليلها

تصل التعديلات اللاحقة على منشورات القناة أيضاً كتحديث مستقل، مع منع تكرار تنبيه النسخة المعدّلة نفسها.

- أضف البوت مسؤولاً في القنوات التي تملكها وتريد مراقبتها؛ يسلّم Telegram منشورات القناة إلى البوت عند توفر صلاحيات الإدارة المناسبة.
- يمكن تحليل منشورات القنوات والمجموعات التي لا تقبل إضافة البوت عبر إعادة توجيه المنشور إلى محادثة الإدارة الخاصة مع البوت نفسه.
- يعالج مسار إعادة التوجيه المحتوى داخل محادثة الإدارة فقط، ويعرض اسم القناة العامة ورابط المنشور عند توفرهما؛ ولا يكشف أسماء أو معرّفات المرسلين الأفراد.
- إذا كان المنشور وسائط بلا نص أو وصف، يرسل البوت تنبيهًا للمراجعة اليدوية.
- أضف NEXUS_MONITOR_CHANNELS في Render اختيارياً، بقائمة معرّفات القنوات أو أسماء المستخدمين مفصولة بفواصل. إذا تُرك فارغاً، يعالج البوت فقط المنشورات التي يسلّمها Telegram إليه.
- يجب ضبط TELEGRAM_ADMIN_CHAT_ID حتى تصل التنبيهات إلى محادثة الإدارة.
- تُخفى أنماط شائعة من المفاتيح والرموز قبل إرسال نص المنشور إلى مزوّد الذكاء الاصطناعي.
- التحليل والمسودات خاصة بالإدارة؛ لا يوجد نشر تلقائي أو رد عام على القنوات.

الأمر /watch أو /مراقبة يعرض تعليمات الإعداد.

## معنى Environment في Render

Environment هي إعدادات تشغيل خاصة بالخدمة. أضفها من صفحة Render الخاصة بالخدمة، ولا تحفظ قيم الأسرار في GitHub:
- `TELEGRAM_BOT_TOKEN`: رمز البوت من BotFather، مطلوب لتلقي أوامر Telegram.
- `TELEGRAM_ADMIN_CHAT_ID`: اختياري؛ عند ضبطه لا يجيب البوت إلا للمحادثة ذات هذا المعرّف.

## نطاق الفهرس

الكتالوج يضم مستودعات GitHub الـ34 التي ظهرت في الجرد، و18 خدمة Render ظاهرة في مساحة العمل وقت آخر جرد. يشمل ذلك معاينات فروع متعددة وخدمات موقوفة؛ وجودها في القائمة لا يعني أنها تعمل. الأوامر للقراءة فقط ولا تنفذ deploy أو restart أو حذفًا أو تعديلًا.


## وضع دردشة AI العامة — Public AI Mode

- الوضع العام متوقف افتراضياً إذا لم يُضبط `NEXUS_PUBLIC_MODE`؛ التفعيل يتطلب اختياراً صريحاً من إعدادات التشغيل.
- حد الاستخدام `NEXUS_PUBLIC_DAILY_LIMIT` يطبق لكل محادثة، ويُحتفظ بعدّاده في ذاكرة عملية البوت الحالية فقط.
- **قيد مهم:** العداد الحالي داخل الذاكرة وليس مخزناً دائماً؛ إعادة تشغيل العملية أو إعادة نشر الخدمة تصفّر العدادات. لذلك لا تعتبره حداً مالياً عالمياً أو وسيلة منع إساءة استخدام مكتملة.
- قبل تفعيل الوضع العام، يلزم وضع مراقبة تكلفة وحدود مزود AI مناسبة والتحقق من سلوك التشغيل الفعلي. لا تُقرأ أو تُعدّل أسرار Render ضمن هذه التعليمات.
